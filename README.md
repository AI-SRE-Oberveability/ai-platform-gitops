# AI platform GitOps

This first P2.13 source slice owns dev/qa alternative Collector values, narrow AppProjects and explicit manual Applications. [The catalog](releases/collector.json) pins real published config/chart/value commits using current repository identities. Chart and value commits are review-branch inputs, pending authorized merges; no future commit hash is invented. Every source change requires a reviewed catalog promotion.

No entry point auto-installs or syncs anything. The two synthetic named clusters are unregistered and do not designate an approved Azure/AKS target. `dev`/`qa` are offline alternatives for one shared Collector, not instructions to run both profiles together. Applications have no finalizers or automated sync/prune/self-heal. Projects permit only four namespaced kinds in `ai-observability`, no cluster-scoped resources or Argo-namespace writes. Config is the sole author of prerequisite namespaces/policies/CRDs; it is referenced as a prerequisite rather than copied or applied here.

`python scripts/validate_gitops.py` validates local source, locked derived Argo schema keywords, ownership preparation and immutable bindings. `--verify-published` additionally fetches only the bounded checksum-locked public source files. CI has read-only contents permission and no Azure/Kubernetes identity. Python dependencies are reused from the approved config hash lock. Vendor schemas derive from exact original Argo 3.6.1 CRDs; their provenance/Apache licence are retained. Offline schema checks do not prove admission/CEL or runtime behavior.

`bootstrap/prepared-ownership.json` is a partial PREPARED-only Collector record with no active writer and no UIDs/readiness/freeze/adoption evidence. Full bootstrap/combined ownership and rollback checks remain. Jaeger/backend readiness, application charts, Argo/control-plane profile/networking, TLS/identity/admission/network/runtime checks and live handover remain pending. Azure deployment stays disabled. Terraform owns Azure/APIM; AKS Python agents and APIM outside AKS remain selected. GitLab credentials and global Git settings are untouched.

References: [external Helm values](https://argo-cd.readthedocs.io/en/stable/user-guide/multiple_sources/), [AppProjects](https://argo-cd.readthedocs.io/en/stable/user-guide/projects/). See the sibling lab HLD/tracker and `docs/collector-gitops-plan.md` for ordered work and remaining gates.
